# Scaled Kotor | Widescreen + UI Scaling
![Markdown Logo](https://raw.githubusercontent.com/J0-o/ScaledKotorWidescreenPatch/refs/heads/main/ks_logo_small.png)

Expands supported resolutions and scales Menus/HUD. (widescreen support)

### Install
- Use with Kotor Patch Manager: https://github.com/LaneDibello/Kotor-Patch-Manager
- Apply all "Scaled" patches with patch manager and then click launch.
- Copy HD UI Menu Pack textures to override
- Copy Scaled Kotor textures to the games override directory, overwrite if asked
- Alt Tab Patch and Movie Patch are recommended.
